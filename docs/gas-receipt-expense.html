応用ハンズオン

🧾 Gmail の領収書を
経費カテゴリに自動仕分けしよう ～ GAS ～

Gmail に届いた「領収書メール」を Google Apps Script (GAS) が読み取り、金額の抽出・カテゴリ判定・スプレッドシートへの仕分けまでを全自動で行う仕組みを作ります。経費精算の面倒な転記作業を、あなたの代わりに GAS が片づけてくれます。

所要時間の目安: 約 60〜80 分 ／ 前提知識: GAS 初級編（スプレッドシート × Gmail）を終えているとスムーズです

はじめに（完成イメージ）

このハンズオンで作るのは、「Gmail に送った領収書を、経費カテゴリごとにスプレッドシートへ自動で振り分ける」仕組みです。完成すると、次のような流れがボタン 1 つ（または定期実行）で回るようになります。

仕組みの全体図

① 領収書の内容をメールで Gmail に送る
    （例: 件名「領収書 1200円 JR東日本」）
        ↓
② GAS が Gmail を検索し、未処理の領収書メールを取得
        ↓
③ 件名・本文から「金額」を抽出し、「カテゴリ」を判定
    （交通費 / 飲食費 / 備品・消耗品 / その他）
        ↓
④ スプレッドシート「経費一覧」に 1 行追記
        ↓
⑤ 処理済みメールにラベルを付けて二重取り込みを防止
        ↓
⑥ トリガーで定期実行（例: 1 時間ごと）＆ 月次集計

ℹ️ このハンズオンでは、領収書の「金額・店名」をメールの件名や本文にテキストで書いて送る方式にします。PDF や写真の中身を読み取る（OCR）方式は少し高度なので、最後の「さらに深掘り」で発展の道筋だけ紹介します。まずはテキストで確実に動く仕組みを完成させましょう。

このハンズオンで学べること

  • GmailApp でメールを検索・取得する方法
  • 正規表現でテキストから金額を抜き出す方法（extractAmount）
  • キーワードルールで自動的にカテゴリ分けする考え方（categorize）
  • Gmail ラベルを使って同じメールを二重に取り込まない工夫
  • トリガーによる定期自動実行と、スプレッドシートでの月次集計
⏱ 約 10 分

Step 1: スプレッドシートを準備する

まずは仕分け結果を書き込む台帳（スプレッドシート）を用意します。Google ドライブで新しいスプレッドシートを作成し、シート名（左下のタブ）を 経費一覧 に変更してください。

1-1. ヘッダー（1 行目）を作る

1 行目に、次の 7 つの見出しを A 列から順に入力します。この列の順番が、あとで書くコードの並び順と対応するので、正確に入れましょう。

列 見出し 入る内容
A取込日時GAS が取り込んだ日時（自動）
Bカテゴリ交通費 / 飲食費 / 備品・消耗品 / その他
C金額抽出した金額（数値）
D店名・摘要メール件名から流用（あとで手直し可）
Eメール件名元メールの件名
F送信元メールの From
GメールID重複チェック用の Gmail メッセージ ID
💡 見出しの文言は自由に変えて構いませんが、列の順番（A〜G の役割）だけはコードと必ず揃えてください。順番がずれると、金額の列にカテゴリが入る…といったズレが起きます。
⏱ 約 5 分

Step 2: GAS プロジェクトを作成する

スプレッドシートに紐づく形で GAS（プログラムを書く場所）を開きます。

  1. スプレッドシート上部のメニューから 「拡張機能」→「Apps Script」 をクリック
  2. 新しいタブでスクリプトエディタが開きます
  3. 最初から書かれている function myFunction() { } は、次の Step ですべて書き換えるので、そのままで OK です
ℹ️ この方法で開いた GAS は、そのスプレッドシートを「操作対象」として最初から知っている状態になります（SpreadsheetApp.getActiveSpreadsheet() でシートを取得できます）。初級編のように ID を指定する必要がないぶん、少しシンプルになります。
⏱ 約 10 分

Step 3: 領収書メールの「送り方ルール」を決める

GAS が仕分けしやすいように、領収書をメールで送るときのちょっとした型（フォーマット）を決めておきます。今回は「件名（や本文）に金額と店名を入れる」というシンプルなルールにします。

3-1. 件名フォーマットの例

件名の例抽出される金額判定されるカテゴリ
領収書 1200円 JR東日本1200交通費
領収書 800円 スターバックス800飲食費
領収書 3,480円 Amazon 文具3480備品・消耗品
領収書 5000円 ○○ホテル5000その他
💡 ポイントは 2 つだけ。① 件名のどこかに「領収書」という言葉を入れる（GAS が検索で見つけるため）。② 「◯◯円」の形で金額を書く（GAS が金額を抜き出すため）。店名はカテゴリ判定のヒントになります。

3-2. テスト用メールを送る

動作確認用に、自分のメールアドレス宛てに上記のような領収書メールを 3〜4 通送っておきましょう。件名だけでも、本文に情報を書いても構いません。

⚠️ 送り先はこの GAS を動かす Google アカウント自身のアドレスにしてください。別アカウントに送ると、GAS からは見つけられません。
⏱ 約 25 分

Step 4: 仕分けスクリプトを実装する

いよいよ本題です。Gmail を検索 → 金額を抽出 → カテゴリを判定 → シートに追記 → 処理済みラベルを付けるという流れを、部品（関数）を組み合わせて作っていきます。まずは 3 つの小さな「部品関数」から作り、最後にそれらを呼び出す本体を組み立てます。

4-1. 設定とカテゴリ判定ルールを書く

スクリプトエディタの中身をすべて消して、まずは設定（自分の環境に合わせて変える値）とカテゴリ判定ルールを書きます。ルールは「キーワードが含まれていたら、このカテゴリ」という表（配列）で管理すると、あとから増やすのがとても簡単です。

After（設定とルールの定義） 
// ▼ 設定（自分の環境に合わせて書き換える）
const SHEET_NAME = '経費一覧';                          // 書き込み先のシート名
const SEARCH_QUERY = 'subject:領収書 -label:経費処理済み'; // Gmail の検索条件
const DONE_LABEL_NAME = '経費処理済み';                  // 処理済みメールに付けるラベル名

// ▼ カテゴリ判定ルール（上から順にチェックし、キーワードが含まれたらそのカテゴリにする）
const CATEGORY_RULES = [
  { category: '交通費',       keywords: ['JR', 'Suica', 'PASMO', 'タクシー', '新幹線', 'ANA', 'JAL', 'メトロ', '交通'] },
  { category: '飲食費',       keywords: ['スターバックス', 'スタバ', 'カフェ', 'レストラン', 'ランチ', '居酒屋', '食堂', 'ドトール'] },
  { category: '備品・消耗品', keywords: ['Amazon', 'ヨドバシ', 'ビックカメラ', '文具', '事務用品', 'Office'] },
];
// ↑ どのルールにも当てはまらなければ「その他」に分類します（判定は 4-3 で実装）
ℹ️ const で定義した値は「定数」です。SEARCH_QUERY の -label:経費処理済み は「『経費処理済み』ラベルが付いていないメールだけ」という意味で、これが二重取り込みを防ぐ仕掛けになります（ラベルは 4-4 で付けます）。

4-2. 金額を抜き出す部品「extractAmount」

次に、テキスト（件名＋本文）から金額を数値で取り出す関数を作ります。「◯◯円」や「¥◯◯」の形を正規表現で探します。下のコードを、先ほどの続きに書き足してください。

After（金額抽出の部品を追加） 
/**
 * テキストから金額（円）を数値で取り出す。見つからなければ 0 を返す。
 */
function extractAmount(text) {
  // まず「1,200円」のように「円」が付く数字を探す
  let match = text.match(/([0-9,]+)\s*円/);
  // 見つからなければ「¥1,200」「￥1,200」のように通貨記号が付く数字を探す
  if (!match) match = text.match(/[¥￥]\s*([0-9,]+)/);
  if (!match) return 0;                       // どちらも無ければ 0
  return Number(match[1].replace(/,/g, ''));  // カンマ（桁区切り）を除いて数値にする
}
💡 match[1] は「カッコ ( ) で囲んだ部分」＝数字だけを指します。replace(/,/g, '') で「3,480」→「3480」に直してから Number() で数値化しています。

4-3. カテゴリを判定する部品「categorize」

4-1 で作った CATEGORY_RULES を上から順に調べ、キーワードが 1 つでも含まれていたらそのカテゴリを返す関数です。どれにも当てはまらなければ「その他」にします。

After（カテゴリ判定の部品を追加） 
/**
 * テキストをキーワードルールで判定し、カテゴリ名を返す。
 * どのルールにも一致しなければ 'その他' を返す。
 */
function categorize(text) {
  for (const rule of CATEGORY_RULES) {
    // rule.keywords のどれか 1 つでも text に含まれていれば true
    const isMatch = rule.keywords.some(keyword => text.includes(keyword));
    if (isMatch) return rule.category;
  }
  return 'その他';
}

4-4. ラベルを用意する部品「getOrCreateLabel」

処理済みメールに付ける Gmail ラベルを取得します。まだ存在しなければ新しく作るようにしておくと、初回実行でも安全です。

After（ラベル取得の部品を追加） 
/**
 * 指定した名前の Gmail ラベルを取得する。無ければ新規作成して返す。
 */
function getOrCreateLabel(labelName) {
  const label = GmailApp.getUserLabelByName(labelName);
  return label ? label : GmailApp.createLabel(labelName);
}

4-5. 本体「sortReceipts」を組み立てる

最後に、これまでの部品を呼び出す本体の関数を作ります。この sortReceipts が、実際に実行するメイン関数です。

After（メイン関数を追加・これで完成） 
/**
 * Gmail の領収書メールを読み取り、カテゴリを判定してスプレッドシートに仕分けするメイン関数
 */
function sortReceipts() {
  // 1. 書き込み先のシートを取得（このスクリプトが紐づくスプレッドシートから）
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(SHEET_NAME);

  // 2. 処理済みラベルを用意（無ければ作成）
  const doneLabel = getOrCreateLabel(DONE_LABEL_NAME);

  // 3. 未処理の領収書メールを検索する
  const threads = GmailApp.search(SEARCH_QUERY);

  // 4. スレッド（メールのまとまり）ごとに処理する
  threads.forEach(thread => {
    thread.getMessages().forEach(message => {
      const subject = message.getSubject();          // 件名
      const body = message.getPlainBody();           // 本文（テキスト）
      const text = subject + ' ' + body;             // 件名＋本文をまとめて判定材料にする

      const amount = extractAmount(text);            // 金額を抽出
      const category = categorize(text);             // カテゴリを判定

      // シートに 1 行追記する（並び順は Step 1 のヘッダー A〜G と揃える）
      sheet.appendRow([
        new Date(),          // A: 取込日時
        category,            // B: カテゴリ
        amount,              // C: 金額
        subject,             // D: 店名・摘要（まずは件名を流用）
        subject,             // E: メール件名
        message.getFrom(),   // F: 送信元
        message.getId(),     // G: メールID（重複チェック用）
      ]);
    });

    // 5. スレッドに「処理済み」ラベルを付け、次回の検索対象から外す
    thread.addLabel(doneLabel);
  });

  // 実行結果をログに残す（[実行ログ] で確認できる）
  Logger.log(threads.length + ' 件のメールスレッドを仕分けしました');
}
⚠️ 書けたら必ずフロッピーアイコン（💾 保存）を押してください。保存しないと、次のステップで実行しても古い状態のままになってしまいます。
⏱ 約 10 分

Step 5: 手動で実行して動作確認する

スクリプトエディタ上部の関数を選ぶプルダウンで sortReceipts を選び、「▶ 実行」ボタンを押します。初回は Google の認証（承認）を求められます。

① 承認が必要

「承認が必要です」

初回実行時に表示されます。「権限を確認」を押して進みます。

② アカウント選択

自分のアカウントを選択

このスクリプトを動かす Google アカウントを選びます。

③ 警告画面

「安全ではないページ」

自作スクリプトのため表示されます。「詳細」→「（プロジェクト名）に移動」を押します。

④ 許可

Gmail とシートへのアクセスを許可

メールの読み取り・ラベル操作・シート編集を許可します。

ℹ️ 今回は Gmail を「読む・ラベルを付ける」操作と、スプレッドシートを「編集する」操作を行うため、その両方の権限を求められます。自分専用の便利ツールを作るための許可なので、内容を確認して進めて大丈夫です。

5-1. 結果を確認する

実行が終わったら、スプレッドシートの「経費一覧」シートを見てみましょう。テスト送信した領収書メールが、カテゴリ・金額つきで 1 行ずつ追記されていれば成功です！

あわせて Gmail を開くと、取り込んだメールに 「経費処理済み」ラベルが付いているはずです。もう一度 sortReceipts を実行しても、同じメールは二重に追加されません（検索条件でラベル付きを除外しているため）。

💡 うまく動かないときは、スクリプトエディタの「実行ログ」を確認しましょう。「0 件のメールスレッドを仕分けしました」と出る場合は、① 領収書メールが届いているか、② 件名に「領収書」が入っているか、③ すでに「経費処理済み」ラベルが付いていないか、を見直してください。
⏱ 約 10 分

Step 6: トリガーで定期実行を自動化する

毎回手で実行するのは大変なので、「時間主導型トリガー」を設定して、GAS に定期的に自動実行させましょう。

  1. スクリプトエディタ左側の時計アイコン（トリガー）をクリック
  2. 右下の「トリガーを追加」を押す
  3. 実行する関数: sortReceipts を選択
  4. イベントのソース: 「時間主導型」
  5. 時間ベースのトリガー: 「時間ベースのタイマー」→「1 時間おき」（お好みで変更可）
  6. 「保存」を押す
💡 これで、領収書メールを送っておけば1 時間以内に自動で仕分けされます。「メールを送るだけで経費台帳ができあがる」状態の完成です！
⚠️ トリガーの実行にも先ほどの権限が使われます。頻度を上げすぎると Google の 1 日あたりの実行時間上限に近づくことがあるため、個人利用なら1 時間〜1 日おきで十分です。

さらに深掘り（集計・カスタマイズ・発展）

① カテゴリのルールを増やす・変える

カテゴリ判定は CATEGORY_RULES の配列を編集するだけで自由にカスタマイズできます。たとえば「通信費」を追加したいなら、次の 1 行を足すだけです。

After（ルールを 1 つ追加） 
const CATEGORY_RULES = [
  { category: '交通費',       keywords: ['JR', 'Suica', 'PASMO', 'タクシー', '新幹線'] },
  { category: '飲食費',       keywords: ['スターバックス', 'カフェ', 'レストラン', 'ランチ'] },
  { category: '備品・消耗品', keywords: ['Amazon', 'ヨドバシ', '文具'] },
  { category: '通信費',       keywords: ['携帯', 'モバイル', 'Wi-Fi', 'プロバイダ', 'docomo', 'au'] }, // ← 追加
];

② 件名タグ方式で「確実に」分類する

キーワードで迷いやすい店（例: コンビニ）は、送るときに自分でカテゴリを件名に書いておく方式と併用すると確実です。例: 件名 領収書 [交通費] 1200円 タクシー。判定関数の先頭に、次の「タグ優先」処理を足します。

After（件名の [カテゴリ] を最優先で使う） 
function categorize(text) {
  // 件名などに [交通費] のようなタグがあれば、それを最優先で採用する
  const tag = text.match(/\[(.+?)\]/);
  if (tag) return tag[1];

  // タグが無ければ、これまで通りキーワードルールで判定する
  for (const rule of CATEGORY_RULES) {
    if (rule.keywords.some(keyword => text.includes(keyword))) return rule.category;
  }
  return 'その他';
}

③ 月ごとにカテゴリ別の合計を出す

集計はコードを書かなくても、スプレッドシートの関数だけでできます。空いているセルに次の式を入れると、カテゴリごとの合計金額が出ます（C 列＝金額、B 列＝カテゴリの場合）。

スプレッドシートのセルに入力 
=SUMIF(B:B, "交通費", C:C)

「ピボットテーブル」（挿入 → ピボットテーブル）を使えば、月 × カテゴリのクロス集計表もクリック操作だけで作れます。

④ さらに発展: PDF・写真の領収書を読み取る

「テキストではなく、PDF や写真の領収書をそのまま送りたい」場合は、次のような発展が考えられます（本ハンズオンの範囲外ですが、道筋として）。

  • 添付ファイルの取得: message.getAttachments() で PDF・画像を取り出す
  • OCR（文字認識）: Google Drive API や Cloud Vision、生成 AI（OpenAI / Gemini）の API に画像を渡して金額・店名を読み取る
  • 読み取った結果を、今回作った extractAmount / categorize に通せば、同じ仕組みで仕分けできます
ℹ️ 生成 AI の API を GAS から呼び出す流れは、GAS 発展編で扱う「OpenAI API 連携」がそのまま応用できます。まずは本編のテキスト方式を土台に、少しずつ拡張していくのがおすすめです。
