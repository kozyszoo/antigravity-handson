OpenAI の AI コーディングエージェントを体験しよう

はじめに

OpenAI Codex とは

OpenAI Codex は、2025年5月に OpenAI がリリースしたクラウドベースの AI ソフトウェアエンジニアリングエージェントです。自然言語の指示からコードを自動生成し、テスト実行、バグ修正、PR 作成まで自律的に行います。

2つのインターフェース

インターフェース 特徴 利用方法
Codex Web版 ChatGPT 内の Codex タブから利用。GitHub 連携でクラウドサンドボックス上でコード生成・PR 作成を自動実行。 chatgpt.com → 左サイドバー「Codex」
Codex CLI ターミナルで動作するオープンソースのコーディングエージェント。ローカル環境でファイルを読み書きし、対話的にコード生成・修正を実行。 npm install -g @openai/codex

操作モード

モード 説明 おすすめ用途
Ask モード リポジトリの読み取り専用クローンを使用。コードを変更せずに分析・回答。 ブレインストーミング、コードレビュー、アーキテクチャ質問
Code モード コード実行・テスト・修正が可能な完全な開発環境を構築。完了後に PR を自動作成。 バグ修正、新機能実装、リファクタリング

Step 1-1: 環境セットアップ

🕐 19:30〜19:45（Step1 合計 30分）

目標

Codex CLI をインストールし、基本的な動作確認を行いましょう。

前提条件

項目要件
Node.jsv22 以上
npmv6 以上（Node.js に同梱）
OSmacOS / Linux / Windows（WSL 推奨）
OpenAI アカウントAPI キーの取得に必要
Gitリポジトリ管理用（推奨）

チェックリスト

1. Node.js のインストール確認

# バージョンを確認（v22 以上であること）
node --version

# npm のバージョンも確認
npm --version
💡 Node.js がインストールされていない場合

nodejs.org から LTS 版をダウンロードしてインストールしてください。

2. Codex CLI のインストール

# グローバルインストール
npm install -g @openai/codex

# インストール確認
codex --version

3. OpenAI API キーの設定

  1. OpenAI API Keys ページにアクセス
  2. 「Create new secret key」で新しいキーを作成
  3. 環境変数に設定: 
    # macOS / Linux
export OPENAI_API_KEY="sk-..."

# 永続化（.zshrc に追記）
echo 'export OPENAI_API_KEY="sk-..."' >> ~/.zshrc
source ~/.zshrc

4. ハンズオン資料のクローン

git clone https://github.com/kozyszoo/codex-handson.git
cd codex-handson

5. 動作確認

# Codex CLI を対話モードで起動
codex

# 起動したら以下のように入力してみましょう:
# → 「こんにちは！今日の日付と曜日を教えて。」

日本語で日付と曜日が返ってくれば成功です 🎉

Codex CLI の承認モード

Codex CLI は、ファイル変更やコマンド実行の承認レベルを3段階で設定できます。

モード動作こんな時に使う
Suggest
最も安全		 すべてのファイル変更・コマンド実行に承認が必要。 初めて使う場合、慎重に進めたいとき
Auto Edit
推奨		 ファイルの変更は自動適用。コマンド実行は承認が必要。 ハンズオン・個人開発。初心者はここから
Full Auto
最速・要注意		 ファイル変更もコマンド実行もすべて自動。 手順が確定した作業、慣れたユーザー向け
⚠️ ハンズオンでの推奨設定

今日のハンズオンでは Auto Edit に設定しておくことを推奨します。

# Auto Edit モードで起動
codex --approval-mode auto-edit

Step 1-2: Codex CLI の基本操作

🕐 19:45〜20:00（Step1 合計 30分）

目標

Codex CLI の基本的な使い方をマスターしましょう。

基本的なコマンド

コマンド説明
codex対話モードで起動
codex "指示文"直接指示を渡して実行
codex --model gpt-4.1モデルを指定して起動
codex --approval-mode auto-edit承認モードを指定
codex --quiet "指示文"非対話モードで実行（CI/CD 向け）

やってみよう

演習 1: プロジェクト構造の確認

codex "このプロジェクトの構造を日本語で説明して"

演習 2: ファイルの作成

codex "Hello World を表示するシンプルな HTML ファイルを作成して。日本語コメント付きで。"

演習 3: コードの修正

codex "index.html にダークモードのCSSを追加して。アクセントカラーは緑系(#10a37f)で。"
💡 Tips: 画像も入力できる

Codex CLI はマルチモーダル対応で、スクリーンショットや図をドラッグ&ドロップして入力できます。「このデザインを再現して」といった指示も可能です。

Step 3: Codex Web版 + GitHub 連携

🕐 20:20〜20:40（20分）

目標

Codex の Web版（ChatGPT 内）を使って、GitHub リポジトリと連携した自動開発を体験しましょう。

Codex Web版のセットアップ

  1. chatgpt.com にログイン（Plus / Pro / Team / Enterprise プランが必要）
  2. 左サイドバーの「Codex」をクリック
  3. 「GitHub を接続する」を選択
  4. アクセスを許可するリポジトリを選択

Ask モードを体験

Ask モードは読み取り専用で、コードベースについての質問に答えてくれます。

このリポジトリの全体構成を日本語で説明して。
主要なファイルとその役割を一覧にして。

Code モードを体験

Code モードでは、コードの変更と PR の作成まで自動実行されます。

README.md に「セットアップ手順」セクションを追加して。
Codex CLI のインストール手順を含めて。
✨ PR が自動作成される

Code モードでタスクが完了すると、Codex は自動で GitHub に PR を作成します。変更内容のサマリー、変更ファイルの一覧、テスト結果が含まれます。

⚠️ セキュリティに関する注意

🔒 Codex のセキュリティモデル
  • Codex は隔離されたクラウドコンテナ内でコードを実行します
  • タスク実行中はインターネットアクセスが無効化されます
  • 提供されたコードのみにアクセスし、外部通信は行いません
  • すべてのアクションは引用・ログ・テスト結果付きで透明性を確保

Step 5: ハッカソンおすすめ戦略 AI-DLC

🕐 21:10〜21:20（10分）

AI-DLC（AI駆動開発ライフサイクル）とは

AI-DLC は、AIを開発プロセス全体の中心的な協力者として活用する新しい開発手法です。

従来の AI 支援型開発AI-DLC
誰が主導？ 人間が主導し、AIに指示 AI がワークフローを主導、人間は承認・方向修正に集中
AI の役割 コーディングの部分的なお手伝い 要件定義〜デプロイまでプロセス全体の協力者

AI-DLC の3つのフェーズ

1. Inception（発案）

アイデアを AI に伝え、要件・ユーザーストーリーを自動生成。チームで確認して修正。

2. Construction（構築）

要件に基づいて AI がコード・テスト・設計を提案。人間は技術的判断に集中。

3. Operations（運用）

AI がデプロイ準備を整備。動作確認・テスト・バグ修正も AI がサポート。

Codex と AI-DLC の対応関係

AI-DLC フェーズやることCodex の対応機能
Inception アイデア → 要件 → 計画 Codex Ask モードで要件定義・壁打ち
Construction コード・デザイン・テスト Codex Code モード / CLI で実装
Operations デプロイ・動作確認 Codex CLI でテスト・PR 作成

Step 6: 活用 Tips 集

OpenAI Codex をさらに使いこなすための Tips と公式リソースをまとめました。

📰 Codex CLI Tips

Tips概要
承認モードを使い分ける suggest（安全）→ auto-edit（バランス）→ full-auto（最速）。慣れるまでは auto-edit 推奨。
画像を入力に使う Codex CLI はマルチモーダル対応。スクリーンショットや図をドラッグ&ドロップして「このデザインを再現して」と指示可能。
非対話モードで自動化 codex --quiet "テストを実行して失敗したら修正して" のように CI/CD に組み込める。
モデルを切り替える codex --model o4-mini で軽量モデル、codex --model o3 で高精度モデルを使い分け。
Codex Web版は PR レビューに最適 GitHub 連携した状態で「最近のPRをレビューして」と依頼すると、コードレビューコメントを自動生成。
