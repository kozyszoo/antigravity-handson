## 19:05 Step 1: テキストから1枚生成（10分）

**やること**: Gemini を開き、言葉だけでマスコットを1枚作る。

1. Gemini を開く（画面共有で実演）→ 画像生成に入る導線を見せる
2. 下のプロンプトをチャットに貼って実行（**参加者にもコピペで一緒に打ってもらう**）:

```
かわいいバナナのキャラクターを作ってください。
- 二足歩行で、笑顔で手を振っている
- フラットでシンプルなマスコットデザイン（太めの輪郭線）
- 背景は無地のパステルイエロー
- 正方形（1:1）、ロゴにも使える清潔感のあるテイスト
```

3. 出てきたら「ここから言葉で直せる」ことを見せる（追い打ちプロンプト）:

```
いい感じです！もう少しだけ目を大きく、色を鮮やかな黄色にしてください。
背景は今のままで OK です。
```

**講師の声かけ**:
- 「箇条書きで条件を分けると伝わりやすい」＝初心者が持ち帰る最初の小ワザ
- 思ったのと違っても正解。**会話で直していけるのが Nano Banana の良さ**
- ⚠つまずき対応: 画像生成が出ない人には「Gemini に『画像を作って』と日本語で頼めばOK」と案内。生成は人により少し時間がかかる旨を先に言う

> 🍌 ここで作ったバナナマスコットを **以降の Step 2/3/5 で使い回す**。最初の1枚を全員ある状態にしてから次へ。

## 19:15 Step 2: 部分編集（8分）

**やること**: Step1の画像をアップロードし、一部だけ直す。

- 背景だけ差し替え:

```
アップロードした画像のキャラクターはそのまま残し、
背景だけを「明るいカフェの店内」に変えてください。
キャラクターの形・色・表情は変更しないでください。
```

- 描き込み（持ち物を足す）:

```
このキャラクターの手に、湯気の立つコーヒーカップを持たせてください。
他の部分はそのままにしてください。
```

**講師の声かけ**: 「**変えない所を言葉で固定する**（形・色・表情はそのまま）」が部分編集のコツ。全消ししないで済む。

---

## 19:23 Step 3: キャラクター一貫性（9分）

**やること**: 同じキャラを別シーンで描く＝「キャラが毎回変わる」初心者の悩みを解消。

- 別シーン:

```
アップロードしたこのバナナのキャラクターを主役にして、
同じ顔・同じ配色・同じ画風のまま、次のシーンを描いてください。
シーン: ノートパソコンの前に座って、楽しそうにタイピングしている
背景: 観葉植物のある明るい部屋
構図: 横長（16:9）
```

- 表情ちがい4枚（盛り上がりポイント）:

```
同じキャラクター・同じ画風のまま、表情とポーズ違いを4種類、
1枚の画像に2×2のグリッドで並べてください。
「喜ぶ / 考える / 困る / 親指を立てる」の4パターンでお願いします。
```

**講師の声かけ**: 「同じ顔・同じ画風のまま」と明示するのが一貫性の合言葉。スタンプ的に使える。

## 19:32 Step 5: 文字入りバナー（10分）★実用の山場

**やること**: 日本語テキスト入りの SNS バナーを作る＝**そのまま告知に使える**。

```
横長（16:9）のSNS用バナーを作ってください。
- 主役: アップロードしたバナナのマスコット（右側に配置）
- 左側に大きく見出しテキスト「バナナ商店、開店！」
- その下に小さめのサブテキスト「毎週日曜オープン」
- 配色はイエロー基調でポップに、文字ははっきり読める太めの書体
```

- 文字だけ後から変更:

```
デザインはそのままで、サブテキストだけ
「毎週日曜オープン」から「毎週土日オープン」に変えてください。
```

**講師の声かけ**:
- 「**日本語の文字を入れた画像が作れる**のが Nano Banana のすごい所」＝今日の一番の持ち帰り
- 自分のコミュニティ/趣味の告知に置き換えて作ってみて、と促す（リクエスト導線）
- ⚠文字が崩れたら「もう一度作って」「太めの書体ではっきり」と頼み直せばよい、と先に保険

## 19:42 Step 4 or 6（時間で選択・8分）

**時間に余裕があれば**どちらか1つ。押していたら飛ばして質疑へ。

- **Step 4 合成**（インパクト重視）:

```
1枚目はマスコットキャラクター、2枚目は商品（マグカップ）です。
このマグカップに、マスコットのイラストをプリントしたデザインにして、
木目のテーブルの上に置いた商品写真風の1枚を作ってください。
照明は自然光、構図は正方形でお願いします。
```

- **Step 6 ブランドキット**（実用重視・SNSアイコン）:

```
このマスコットの顔をアップにした、SNSアイコン用の正方形画像を作ってください。
背景は無地のイエロー、シンプルで小さく表示しても分かりやすいデザインで。
```

> おまけ枠: 余れば「Gemini に頼むと Docs/PDF をそのまま出してくれる」ファイル生成を1分だけ覗く（告知で言及済み）。
