Curriculum Proposal

新規カリキュラム提案

過去のトレーニングアワー（2026/05/25・06/08・06/22 実施分）のアンケート回答を分析し、
参加者のニーズを反映した 8つの新コース と 運営改善案 を提案します。

01 — Analysis

アンケートから抽出された3つの課題

アンケートデータを分析した結果、参加者の声から以下の3つの主要な課題・ニーズが浮かび上がりました。 新コースは、これらの課題を直接解消することを狙いとして設計しています。

①

レベル差・進行スピードと
環境構築の壁

初学者や1年生が、CLI/CUI・MCP・IDE などの専門用語や Git/GitHub 連携、環境構築の段階でついていけなくなるケースが見られます。

  • 「事前の知識が不足していた、説明のスピードが速すぎた」
  • 「CLI や MCP、IDE などの専門用語の説明が省略されていた」
  • 「環境構築や Git、GitHub の整理の仕方に苦戦した」
  • 「最速で終わらせると次のミッションが出て、深く学べない」
②

セキュリティと権限設定への
強い不安

AI エージェント（Claude Code や Antigravity 等）を実務や個人開発で使うにあたり、セキュリティ上の懸念や適切な権限（Read/Write/Command 実行）の与え方を学びたいという要望があります。

  • 「セキュリティ面が不安。どこまで権限を与えるべきか」
  • 「個人 PC から仕事の資料にアクセスできる環境が不安」
  • 「個人用 PC を2台持ちにすべきか迷っている」
③

すぐ使える実践的ツールの
活用ニーズ

画像生成を一歩進めたプロンプトエンジニアリングの思考プロセスや、特定ツール（NotebookLM・Deep Research・Google Sites）を組み合わせた実践的カリキュラムが求められています。

  • 「プロンプトをどう思いつけばいいのか追いつけなかった」
  • 「NotebookLM の活用方法や実際の活用例を知りたい」
  • 「研究開発分野での生成 AI 利用法（Deep Research 等）」
  • 「Google Sites 等で簡単にホームページが作れると嬉しい」

02 — New Courses

新規カリキュラム提案（8つの新コース）

抽出した課題・ニーズに基づき、レベル別・テーマ別に8つの新規ハンズオンコースを提案します。

🛡️
コースA ／ 中〜上級者向け

AIエージェント時代の
セキュリティ＆開発ガバナンス実践

AI コーディングエージェント（Antigravity, Claude Code 等）を安全に利用するためのセキュリティ特化コース

狙い：AI エージェントに与える権限のリスクを正しく理解し、安全な開発環境を構築する。

主な内容

  • AI エージェントが要求する権限（Read / Write / Command 実行）の仕組みとリスク分析
  • サンドボックス環境（Docker 等）や独立した Worktree を用いた安全な実行環境の構築
  • 個人 PC と仕事用データの適切な分離方法、機密情報の漏洩を防ぐフィルタリング設定
  • AI エージェントの利用ガイドライン（ガバナンス）の策定ハンズオン
🚀
コースB ／ アンバサダー向け

「即戦力」AIツール実践
NotebookLM × Deep Research × Google Sites

複数の最新 AI/Web ツールを組み合わせて、研究や情報発信のアウトプットを作るコース

狙い：最新 AI でリサーチ・分析を行い、その成果をノンコードで Web ページとして公開する一連の流れを体験する。

主な内容

  • Deep Research：AI 自律ブラウジングを用いた網羅的・専門的な文献調査
  • NotebookLM：複数の PDF・リンク・メモをソースに、要約・比較・FAQ を生成
  • Google Sites：整理した情報を基に、イベント告知やアンバサダー紹介ページを15分で構築
🌱
コースC ／ 初学者・準備編

ゼロから始める
Git/GitHub & AIエージェント入門

専門用語や環境構築の壁を取り払い、Antigravity 等を動かすための土台を作るコース

狙い：CLI 操作や Git/GitHub、AI エージェントの起動に必要な基本知識を、手を動かしながらゆっくり学ぶ。

主な内容

  • 専門用語のやさしい解説（CLI・IDE・MCP・エージェントとは？）
  • Git/GitHub の基本（クローン・ブランチ・コミット・Push）と、AI 生成物のファイリング・整理のコツ
  • Antigravity 等の基本セットアップを講師と一緒に1ステップずつ完了（トラブルシューティング体験付き）
  • つまずいた時の対処法（ログの読み方、やり直し方）
⚖️
コースD ／ 中級者向け

実践！責任あるAI（AI Ethics）＆
ハルシネーション評価ワークショップ

AI の倫理リスクや偽情報（ハルシネーション）を評価・対策し、信頼性の高いアウトプットを作るコース

狙い：生成 AI の倫理的な問題点や技術的限界（ハルシネーション、バイアス）を理解し、責任ある AI 活用ができるようになる。

主な内容

  • AI Ethics の基本：著作権・プライバシー・バイアス・公平性に関するディスカッション
  • ハルシネーションの発生メカニズムと、出力情報の信頼性を検証（Fact-checking）するプロセス
  • プロンプトレベルでのバイアス・リスク軽減策（セーフガードの設定方法）
  • アンバサダーとしての倫理的な発信方法と、責任ある AI 利用のチェックリスト作成
🔀
コースE ／ 上級者向け

マルチAI・ハイブリッド開発ワークフロー
Codex × Claude × Antigravity 使い分け編

各 AI コーディングエージェントの特性を理解し、タスクに応じて最適なツールを選択・連携するコース

狙い：複数の AI エージェントの強みを活かし、1つのプロジェクトでハイブリッドに使いこなすプロの開発フローを体感する。

主な内容

  • 3大 AI エージェントの特徴比較とユースケース別の使い分け（デバッグ・新規実装・ドキュメント・テスト自動化など）
  • CLI ツールとエージェント連携のメリット・デメリット
  • 実践タスク：Claude Code で超高速デバッグ → Antigravity の並列マルチエージェントでリファクタリング → Git ワークフローで PR 作成
  • 複数 AI を同時利用する際の設定と、環境干渉を防ぐベストプラクティス
📣
コースF ／ 初〜中級者向け

AI×デザイン：アンバサダーのための
効果的なSNS発信＆アウトリーチ戦略

生成AIを活用し、ターゲットに響くコンテンツ作成と情報発信を実践するコース

狙い：AIによるターゲット分析・コピーライティング・画像生成を組み合わせ、広報活動の質とスピードを飛躍的に高める。

主な内容

  • AIを用いたターゲットペルソナ分析と興味関心の言語化
  • エンゲージメントを高めるSNS告知テキストのドラフト自動生成
  • 画像生成AI（Nano Banana 等）によるブランドイメージに沿ったアイキャッチ画像制作
  • クリック率を高めるレイアウト配置と、AIを活用した発信プランの策定
🌐
コースG ／ 初〜中級者向け

対話でつくる！個人ホームページ＆
ポートフォリオサイト爆速構築

AI エージェントを相棒に、自分だけのWebサイトをノンコードから構築する入門コース

狙い：HTML/CSSの基礎を学びつつ、AIの指示だけでレスポンシブなWebページを完成させ、インターネット上に公開する。

主な内容

  • AIエージェントへの適切な指示出し（プロンプト）によるWebデザインの選定
  • 対話型で進めるHTML/CSSコーディングとレスポンシブ対応（スマホ表示）
  • AIが作ったコードの構造理解と、簡単なテキスト・画像変更のやり方
  • GitHub Pages を使った完全無料でのWebサイト公開手順
🎵
コースH ／ 中級者向け

AIと創る音と映像：MusicFX ×
画像生成で作るプロモーション動画

音楽生成AIと画像生成AIを駆使し、30秒のイベント告知ショート動画を作るコース

狙い：AI（MusicFXやSuno等）による作曲・BGM生成と、画像素材を組み合わせ、クリエイティブな映像を制作する。

主な内容

  • 音楽生成AI（MusicFX 等）を用いたイベントの雰囲気に合うBGM/効果音の作成
  • 告知テキストとマスコット画像を組み合わせたシーン素材の画像生成
  • AI生成した音声・画像アセットを動画編集ツールで統合するワークフロー
  • テンポを合わせた30秒ショート動画（縦型・横型）の書き出しと発信方法

03 — Operations

運営・進行の改善提案

「スピードが速すぎる」「時間の制約」というアンケートの指摘を解消するため、以下の運営改善を行います。

📋

事前のアジェンダ・アセット共有

当日デバイスを切り替えた際にも迷わないよう、Discord 等で事前にタイムラインと進行 URL（アジェンダ）を共有します。

💡

「プロンプト発想プロセス」の解説

コピペ用プロンプトの提示だけでなく、「なぜこのプロンプトになったのか」の思考ステップ（目的の明確化 → 制約の指定 → 出力フォーマットの固定）を可視化して説明します。

📺

アーカイブと自習資料の導線強化

スピードについていけなかった参加者が後から自分のペースで復習できるよう、トラブルシューティング付きの解説動画／ドキュメント（docs/ 配下）を体系化して案内します。
