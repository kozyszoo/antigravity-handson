## 🏗️ Antigravityの核心技術（19:15〜19:30）

### 1. Agent-First Architecture（5分）

**スライド**: Agent-First アーキテクチャ図

**デモポイント**:
- AIが自律的にタスクを計画・実行・検証
- Planning Mode での実行フロー
- Artifacts（実装計画書）の自動生成

**トーク例**:
> Antigravity の最大の特徴は「Agent-First」です。
> AIが単なるコード補完ツールではなく、自律的なエージェントとして
> タスクを計画→実行→検証のサイクルを回してくれます。

### 2. Dual View System（5分）

**スライド**: Editor View vs Agent Manager の比較図

**デモポイント**:
- Editor View: コード編集に特化
- Agent Manager: AIとの対話に特化
- `Cmd + E` で切り替え

**実演**:
1. Editor View を開く
2. `Cmd + E` で Agent Manager に切り替え
3. 再度 `Cmd + E` で Editor View に戻る

**トーク例**:
> Antigravity には2つのViewがあります。
> Editor View はコード編集、Agent Manager はAIとの対話。
> Cmd + E で瞬時に切り替えできます。

### 3. Multi-Model Support（5分）

**スライド**: モデル選択画面

**デモポイント**:
- Gemini 3 Pro（推論・計画）
- Claude Sonnet 4.5（コード生成）
- Nano Banana（画像生成）
- 用途に応じて使い分け

**トーク例**:
> Antigravity は複数のAIモデルを使い分けられます。
> 計画立案は Gemini、実装は Claude、画像生成は Nano Banana など、
> タスクに応じて最適なモデルを選択できます。

### デモ実行時の注意点

1. **Planning Mode を使う**
   - Fast Mode はミスりやすいので避ける
   - 計画を見せることで、AIの思考プロセスを可視化

2. **エラーが出た場合**
   - 「続きを実装して」と依頼
   - モデルを切り替える（Gemini → Claude）
   - レート制限の場合は、その旨を説明

3. **時間配分**
   - 各ステップで想定より早く終わった場合、質疑応答を挟む
   - 遅れている場合、Step 4 の調整部分をスキップ

4. **トラブルシューティング**
   - ネットワーク障害: オフラインデモ動画を用意
   - AI応答遅延: 事前に生成した結果をコピペ
   - ブラウザクラッシュ: 別ブラウザで再実行

### 質疑応答用FAQ

**Q1: 無料枠で十分使えますか？**
- A: Free プランでも基本機能は使えます。Gemini 3 Pro は制限ありますが、Claude Sonnet 4.5 は無料で利用可能です。

**Q2: セキュリティは大丈夫ですか？**
- A: DevContainer で実行すれば、ホストOSを保護できます。機密情報は GEMINI.md で制御可能です。

**Q3: 既存プロジェクトに導入できますか？**
- A: はい。GEMINI.md を配置するだけで、既存プロジェクトでも活用できます。

**Q4: チーム開発で使えますか？**
- A: Enterprise プランでは、チーム共有 Artifacts やカスタムルールが使えます。

**Q5: 他のエディタと併用できますか？**
- A: Antigravity は VS Code ベースなので、既存の拡張機能も使えます。
