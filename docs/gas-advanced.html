発展編

🚀 生成AI活用コーディングハンズオン
～ Google Apps Script (GAS) 応用と発展 ～

初級編で作ったタスク通知アプリに、生成 AI を相棒にしてオリジナルの機能を追加していきます。「自分でゼロから書く」のではなく「AI に書かせて動かす」体験がテーマです。

前提: 初級編のタスク通知アプリが完成していること

はじめに

ℹ️ この発展編は初級編の続きです。まだの方は先に 初級編（タスク通知アプリ作成） を完了させてから戻ってきてください。

初級編では、毎日のタスクを Gmail で自動通知するアプリを作りました。発展編では、各自が契約・利用している文章系の生成 AI（ChatGPT / Gemini / Claude など）を活用して、このアプリにオリジナルの要素を付け加えていきます。

🎯 この発展編のゴール

  • 「やりたいこと」を生成 AI に伝えてコードを書いてもらう進め方のコツを身につける
  • タスク通知アプリを 5 つの方向に拡張する例を体験する（まとめ送信 / 優先度 / 完了管理 / カレンダー連携 / Gemini API）
  • エラーが出ても、AI に質問しながら自走できるようになる

基本姿勢

Step 1: 生成 AI を相棒にする「進め方」

発展編で一番大事なのは、コードを丸暗記することではなく、生成 AI とのやり取り方を覚えることです。実装は次のサイクルを回すだけで進みます。

🔑 AI に質問するときの 3 つのコツ

  1. 今のスクリプトを丸ごと貼り付ける … AI はあなたのコードを見られません。まずは現状のコード全文を貼り、その上で依頼します。
  2. 「何をしたいか」を一文で伝える … 例:「このスクリプトの複数のタスクのお知らせを1つのメールで送信できるようにして」
  3. エラーはそのままコピペして聞く … 実行ログに出たエラー文を貼って「このエラーの原因と直し方を教えて」と聞くのが最速です。
💡 基本のプロンプトのかたち
（スクリプトを全文貼り付け） の後に、改行して ↑このスクリプトで、〇〇できるようにして と添えるだけ。これだけで AI が書き換え案を返してくれます。

📬 まとめ送信

Step 2: 複数タスクを 1 通のメールにまとめる

初級編のコードは、今日のタスクが 3 件あればメールも 3 通届いてしまいます。これを1 通にまとめて送るように変えてみましょう。

🤖 Gemini にこう聞く
このスクリプトの複数のタスクのお知らせを1つのメールで送信できるようにして
💡 うまくいかないとき / 答え合わせ用のコードを見る

ポイントは、forEach でその都度送るのをやめて、いったん本文を 1 つの文字列に組み立ててから、最後に 1 回だけ送ることです。

// 今日のタスク（tasksToday）が抽出された後...

// タスクが1件もなければ送らない
if (tasksToday.length === 0) return;

const recipientEmail = 'your.email@example.com'; // 自分のアドレスに置き換える

// 本文を1つにまとめる（箇条書き）
let body = '本日のタスクは以下の通りです。<br><ul>';
tasksToday.forEach(task => {
  body += `<li>${task[0]}</li>`; // task[0] = タスク名
});
body += '</ul>';

// まとめて1通だけ送信
MailApp.sendEmail({
  to: recipientEmail,
  subject: `本日のタスク（${tasksToday.length}件）`,
  htmlBody: body
});
ℹ️ htmlBody に <ul><li> などの HTML タグを書くと、メールが箇条書きで見やすく表示されます。

🔺 優先度

Step 3: タスクに優先度を追加する

タスクの重要度に応じて優先度を設定し、通知で強調表示することで、重要なタスクに注意を向けやすくできます。

📋 準備

  1. スプレッドシートに C 列「通知先メール」を追加し、各行に送り先のアドレスを入れる
  2. その隣に D 列「優先度」を追加し、各タスクに「高」「中」「低」などの値を入力する
🤖 Gemini にこう聞く
このスクリプトに、タスクの優先度を追加できるようにして
💡 うまくいかないとき / 答え合わせ用のコードを見る

優先度の列を読み取り、値に応じてメッセージを変えます。列の番号は 0 から数えるので、A列＝task[0]、B列＝task[1]、C列＝task[2]、D列＝task[3] になります。

列中身コードでの書き方
Aタスク名task[0]
B実施日task[1]
C通知先メールtask[2]
D優先度task[3]
tasksToday.forEach(task => {
  const taskName = task[0];
  const recipientEmail = task[2]; // 通知先（メール列を使う場合）
  const priority = task[3];       // 優先度を取得

  // 優先度に応じてメッセージを変更
  let message = `本日のタスク: ${taskName}`;
  if (priority === "高") {
    message = `<h1>重要!</h1> 本日のタスク: ${taskName}`; // HTML タグで強調
  } else if (priority === "低") {
    message = `本日のタスク: ${taskName} (優先度: 低)`;
  }

  // ...（Gmail 送信処理）...
});

✅ 完了管理

Step 4: タスクの完了状況を管理する

完了状況をスプレッドシートで管理し、未完了のタスクだけ通知すれば、終わったタスクの通知に煩わされなくなります。

📋 準備

  1. スプレッドシートに E 列「完了状況」を追加する（Step 3 で D 列まで使ったので、その隣）
  2. タスクが終わったら「完了」と入力する
🤖 Gemini にこう聞く
このスクリプトで、タスクが未完了のものだけ通知するようにして
💡 うまくいかないとき / 答え合わせ用のコードを見る

完了状況の列（E 列＝task[4]）が「完了」のものを通知対象から外す、もしくは取り消し線で表示します。

tasksToday.forEach(task => {
  // ...
  const status = task[4]; // 完了状況を取得

  // 完了状況に応じてメッセージを変更
  if (status === "完了") {
    message = `<strike>${message}</strike> (完了)`; // 取り消し線で表示
  }

  // ...（Gmail 送信処理）...
});
💡 「完了したタスクは通知自体を飛ばしたい」場合は、if (status === "完了") return; のように forEach 内で return させると、その行はスキップされます。AI に「未完了だけ送って」と依頼すればこの形を提案してくれます。

📅 カレンダー連携

Step 5: Google カレンダーと連携する

Google カレンダーの予定をタスクとして扱い、Gmail で通知すれば、スケジュール管理とタスク管理を統合できます。

🤖 Gemini にこう聞く
このスクリプトで、Google カレンダーから今日の予定も取ってきて、タスクと一緒に通知できるようにして
💡 うまくいかないとき / 答え合わせ用のコードを見る

GAS には標準で CalendarApp が用意されており、その日の予定を簡単に取得できます。取得した予定を、タスクの配列に追加してから通知します。

// Google カレンダーから今日の予定を取得
const calendarId = 'your.calendar.id@group.calendar.google.com'; // カレンダー ID に置き換える
const events = CalendarApp.getCalendarById(calendarId).getEventsForDay(today);

// 予定をタスクとして追加
events.forEach(event => {
  tasksToday.push([event.getTitle(), formattedToday, 'your.email@example.com']);
});

// ...（この後、通常どおり Gmail 通知を送信）...
ℹ️ カレンダー ID は、Google カレンダーの「設定と共有」→「カレンダーの統合」から確認できます。自分のメインカレンダーなら、ご自身の Gmail アドレスがそのまま ID になります。

🤖 AI 連携

Step 6: 文章生成 AI（Gemini API）の活用

仕上げに、Gemini を GAS から呼び出して、タスク名から通知文を自動生成させてみましょう。たとえば「秘書風の文面」で通知させる、といった遊びができます。ここまでは画面の Gemini に聞きながら進めてきましたが、今度はスクリプトの中から Gemini を呼び出すわけです。

🤖 Gemini にこう聞く
このスクリプトから Gemini API を呼び出して、通知の文面を秘書風に書いてもらうように書き換えて

📋 準備

  1. Google AI Studio で API キーを取得する（普段使っている Google アカウントでそのまま作れます）
  2. GAS から UrlFetchApp を使って Gemini の API を呼び出す
💡 無料の枠内で試せます。 Gemini API には無料枠があり、クレジットカードの登録なしで始められます。このハンズオンで動かす回数なら、無料枠に十分おさまります。
💡 うまくいかないとき / 答え合わせ用のコードを見る

GAS には外部 API を叩くための UrlFetchApp があります。タスク名を渡して、件名や本文を Gemini に作らせます。

// タスク名から、秘書風の通知文を Gemini に生成してもらう関数
function generateMessage(taskName) {
  const apiKey = 'YOUR_GEMINI_API_KEY'; // 自分の API キーに置き換える
  const model = 'gemini-flash-latest';  // 速くて安いモデル
  const url = `https://generativelanguage.googleapis.com/v1beta/models/${model}:generateContent`;

  const payload = {
    systemInstruction: {
      parts: [{ text: 'あなたは丁寧な秘書です。' }]
    },
    contents: [{
      parts: [{ text: `本日のタスク「${taskName}」を、秘書風に一言添えて知らせて。` }]
    }]
  };

  const options = {
    method: 'post',
    contentType: 'application/json',
    headers: { 'x-goog-api-key': apiKey }, // API キーはヘッダーで渡す
    payload: JSON.stringify(payload)
  };

  const response = UrlFetchApp.fetch(url, options);
  const json = JSON.parse(response.getContentText());
  return json.candidates[0].content.parts[0].text; // 生成された文章を返す
}

この関数を作っただけでは何も変わりません。メールを送っているところから呼び出して、生成された文章を本文に使います。

tasksToday.forEach(task => {
  const taskName = task[0];

  // Gemini に秘書風の文面を書いてもらう
  const message = generateMessage(taskName);

  MailApp.sendEmail({
    to: recipientEmail,
    subject: `本日のタスク: ${taskName}`,
    htmlBody: message // 生成された文章をそのまま本文にする
  });
});
⚠️ API キーの取り扱いに注意！ API キーはパスワードと同じです。スクリプトをそのまま他人に共有・公開すると不正利用される恐れがあります。共有時はキーを削除するか、PropertiesService（スクリプトプロパティ）に保管する方法を AI に聞いてみましょう。
ℹ️ モデル名に gemini-flash-latest と書いておくと、Google 側で新しい版が出たときに自動でそちらを向きます。特定の版に固定したいときは gemini-3.7-flash のようにバージョンを書きます。無料枠には1分あたり・1日あたりの回数制限があり、超えるとエラー（429）が返ります。請求の設定をしない限り、勝手に課金されることはありません。
